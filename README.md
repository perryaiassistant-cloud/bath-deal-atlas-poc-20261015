# Bath / Deal Atlas

Static proof of concept featuring ten fictional properties around Bath. No real listings or paid APIs.

Run `npm install && npm run start` and open the local URL shown by Vite. Run `npm test` for calculation checks and `npm run build` for a production build.

Ranking uses estimated profit divided by total project cost. The model includes purchase costs, works, contingency and holding costs. It excludes tax, finance, selling fees and planning outcomes. Figures are illustrative and not investment advice.
